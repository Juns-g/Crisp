Crisp
对比 指南 GitHub EN

macOS 藏起来的显示器控制，都装进这一个菜单栏面板。

Crisp 是 BetterDisplay 和 Lunar 的免费开源平替，连它们的 Pro 功能也免费。

下载 macOS 版 GitHub 仓库
$ brew install --cask didriksg/tap/crisp 点击复制

开源（MIT），已收录于 awesome-mac。

一块面板，把每块屏都调到位。

任意显示器都能 HiDPI

给外接显示器补上 Retina 级的缩放分辨率，不再发虚或太小，2K 及以上自动配好、且始终跑满面板刷新率。

平滑缩放

以更小的步进微调界面大小，远超 macOS 默认的那几档。这正是很多人装 BetterDisplay 就为了用的灵活缩放，现在内建。

哪块屏都能调亮度

外接屏走 DDC 硬件控制，不支持的用软件兜底；键盘亮度键可作用在光标所在的屏、全部屏，或你指定的几块。

预设

把分辨率、亮度、排列存成一套，一键切换。

排列

拖拽摆位、一键切换主显示器。

系统开关

深色模式、夜览、原彩显示，直接在面板里切，不用进系统设置。

色彩

ICC 配置切换，外加 gamma、对比度、增益微调。

虚拟显示器

创建 HiDPI 虚拟屏，用于直播、随航或无头 Mac。

更多

合并亮度滑块、自动亮度跟随内建屏、保持唤醒、隐藏刘海、开机启动。

所有操作，都在菜单栏里。
