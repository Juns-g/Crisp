Crisp

macOS 藏起来的显示器控制，都装进了这一个菜单栏面板。

BetterDisplay 和 Lunar 的免费开源平替，连它们收费的功能也免费。

下载 macOS 版 GitHub 仓库
$ brew install --cask didriksg/tap/crisp 点击复制

用 Homebrew 安装，不会有任何安全警告。开源（MIT），已收录于 awesome-mac。

功能

任意显示器都能 HiDPI

给外接显示器补上 Retina 级的缩放分辨率，2K 及以上会自动配好。

哪块屏都能调亮度

外接屏走 DDC 硬件控制，不支持的用软件兜底；键盘亮度键作用在光标所在的那块屏上。

预设

把分辨率、亮度、排列存成一套，一键切换。

排列

拖拽摆位、一键切换主显示器。

系统开关

深色模式、夜览、原彩显示，直接在面板里切，不用进系统设置。

色彩

ICC 配置切换，外加 gamma、对比度、增益微调。

虚拟显示器

创建 HiDPI 虚拟屏，用于直播、随航或无头 Mac。

更多

合并亮度滑块、自动亮度跟随内建屏、隐藏刘海、开机启动。

面板长这样

免费开源，MIT 许可。要求 macOS 15 及以上。
